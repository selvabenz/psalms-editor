# v0.4 Test Report

Date: 2026-09-18

## Automated checks passed

### Static and data-integrity suite

- JavaScript syntax for `app.js` and `source-manager.js`.
- Every DOM ID referenced by the application exists.
- Annotation schema version is `0.4.0` and accepts Psalms 1–150.
- The generated TAHOT bundle contains all 150 Psalms, 2,579 verse/superscription records, and 19,595 tokens.
- TAHOT identity, CC BY 4.0 licence metadata, token totals, and canonical token IDs are internally consistent.
- All 19,595 unique Hebrew token IDs referenced by the supplied 150 annotation files resolve against the bundled TAHOT data.
- Existing v0.1, v0.2, and v0.3 migration and annotation workflow integrity checks continue to pass.

Run with:

```sh
python tests/static_integrity_test.py
```

### Runtime annotation workflow suite

The deterministic DOM harness verifies application startup, Psalm selection, v0.1–v0.3 migration, schema v0.4 import, separate per-Psalm storage, batch import through Psalm 150, editing workflows, and TAHOT display. It also imports the supplied `PSA002.annotations.json` when `PSALM_ANNOTATION_FIXTURE` is set and confirms all 24 segments, 12 parallel groups, and 12 verses render.

Run with:

```sh
node tests/runtime_smoke_test.js
```

### USFM/SFM source-manager suite

- Parses `\id PSA`, `\c`, `\v`, poetry continuations, Psalm titles, and inline word markup.
- Removes notes and cross-references from display text.
- Rejects non-Psalms books.
- Merges multiple Psalms files for one language.
- Persists and removes imported language sources separately from annotations.

Run with:

```sh
node tests/source_manager_test.js
```
